## 🌟 Возможности приложения

### 1. Интерактивный визуальный конструктор шаблона
* **Загрузка любых фонов:** поддержка бланков в форматах **`PDF`**, **`PNG`**, **`JPG`**, **`JPEG`**, **`BMP`**.
  * Для многостраничных или векторных PDF-бланков первая страница автоматически растрируется в сверхчеткое изображение 300 DPI через встроенный Windows-конвертер.
* **Любой формат и ориентация:** автоматическая поддержка A4, A3, A5, книжной, альбомной ориентации или любого нестандартного соотношения сторон.
* **Drag & Drop:**
  * Перетаскивайте поля мышью в любое место диплома.
  * Тяните за маркер в правом нижнем углу для изменения размера рамки.
  * Перетаскивайте файлы дипломов прямо из проводника Windows в окно программы.
* **Точное позиционирование и направляющие:**
  * **Умные направляющие (Smart Guides):** при перемещении блоки автоматически выравниваются относительно центра листа и других блоков с отображением розовых линий привязки и бейджей.
  * **Центральные направляющие:** кнопка `[ 📐 Центр ]` для постоянного отображения вертикальной и горизонтальной оси симметрии.
  * **4 настраиваемые направляющие линии:** 2 вертикальные и 2 горизонтальные пунктирные линии бирюзового цвета (`#0284C7`), которые можно свободно перетаскивать мышью или задавать точные координаты в пикселях с быстрым сбросом на стандартные поля 10%. Блоки текста автоматически примагничиваются к ним при перемещении.
  * **Перемещение кнопками и стрелками:** панель с кнопками `[ ⬅ Влево ]`, `[ ⬆ Вверх ]`, `[ ⬇ Вниз ]`, `[ ➡ Вправо ]` с настраиваемым шагом (1 px, 5 px, 10 px, 25 px) и мгновенное управление с клавиатуры стрелками (с ускорением `Shift` x5).
* **Свойства текстовых блоков:**
  * **Шрифт:** системные шрифты Windows (*Georgia, Times New Roman, Arial, Calibri, Segoe UI* и др.).
  * **Размер шрифта:** ползунок от 10 до 100 pt.
  * **Начертание:** Жирный (**B**), Курсив (*I*).
  * **Выравнивание:** по левому краю, по центру, по правому краю.
  * **Палитра и Пипетка (Eyedropper):** палитра быстрых пресетов (Черный, Золотой, Синий, Бордовый, Белый), ручной ввод HEX-кода, а также **встроенная экранная пипетка** с увеличенной лупой и предпросмотром цвета в реальном времени при клике на квадрат цвета `[ 💧 ]`.
  * **Автоматическое сжатие шрифта (Auto-shrink):** длинные фамилии автоматически пропорционально уменьшаются в размере шрифта, чтобы идеально помещаться в заданные границы.
* **Библиотека пресетов шаблонов (*.dpt):**
  * Сохранение кастомных шаблонов вместе со всеми блоками, оформлением и направляющими.
  * Быстрый выбор сохраненных шаблонов из выпадающего списка в один клик.

### 2. Таблица участников
* **Динамические колонки:** таблица автоматически генерирует столбцы на основе полей текущего шаблона.
* **Удобные способы наполнения:**
  1. **Вставка из Excel (Ctrl+V):** скопируйте диапазон в Excel / Таблицах и нажмите `📋 Вставить из Excel`.
  2. **Импорт CSV/TSV:** поддержка кодировок UTF-8 и Windows-1251 с автоматическим определением разделителей.
  3. **Ручной ввод:** быстрое добавление и редактирование строк прямо в таблице.
  4. **Экспорт в CSV:** выгрузка текущей базы участников в файл.

---

### 3. Пакетная генерация и печать
* **Живой предпросмотр (Live Preview):** постраничный просмотр дипломов для каждого участника перед запуском генерации.
* **Режимы экспорта:**
  * **Единый многостраничный PDF:** все дипломы в одном файле для типографии.
  * **Отдельные файлы PDF:** персональный PDF на каждого участника.
  * **Изображения PNG (300 DPI):** наивысшая четкость для фотопечати.
  * **Прямая печать на принтер:** отправка пачки прямо на печать в выбранный принтер.
* **Шаблоны имен файлов:** поддержка масок, например `{Номер}_{ФИО}_{Место}`.

---

### 4. Отладка и диагностика (Режим разработчика)
* Для удобной работы панель отладки по умолчанию скрыта.
* Нажмите сочетание клавиш **`Ctrl + Shift + D`** в окне приложения, чтобы отобразить панель отладочных инструментов (логирование действий, создание скриншотов кликов и кнопки быстрого открытия папок логов и снимков).

## 🛠️ Архитектура и технологии

* **Платформа:** .NET Framework 4.8 / 4.0, WPF (C#).
* **Рендеринг:** Векторный рендеринг через `DrawingVisual` + `RenderTargetBitmap` с масштабированием в 300 DPI.
* **Генерация PDF:** встроенный автономный модуль `PdfWriter.cs` (стандарт PDF 1.4 с аппаратным сжатием JPEG DCTDecode) — **0 внешних зависимостей**.
* **Сериализация:** стандартный `System.Web.Script.Serialization`.
